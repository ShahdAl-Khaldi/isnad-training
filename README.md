# نظام التدريب الميداني · إسناد

نظام Laravel كامل للتسجيل بالتدريب الميداني: تقديم ← مقابلة ← قبول ← دفع وتثبيت المقعد، مع لوحة إدارة لإسناد.

## شو فيه

**للطالب**
- صفحة رئيسية فيها التخصصات والرسوم وخطوات التسجيل.
- نموذج تقديم (الاسم، الواتس، الجامعة، التخصص، المسار، الساعات 72/120، رابط الأعمال، الأهلية، ملاحظات) مع شرط مهلة الدفع.
- صفحة خاصة لكل طالب (رابط سري + كود مثل `ISN-12345`) بيشوف فيها حالته خطوة بخطوة.
- لما ينقبل: عدّاد تنازلي للمهلة، أرقام التحويل (بنك فلسطين، جوال باي...) مع زر نسخ، ورفع صورة التحويل.
- لو خلصت المهلة: المقعد بيتحرر وبيقدر ينضم لقائمة الانتظار.
- صفحة "تتبّع طلبك" بالكود ورقم الواتس.

**التصميم**
- وضع فاتح وغامق (زر الشمس/القمر)، واللوقو بلونه الأزرق بالوضع الفاتح.
- حركات: خلفية متحركة بالصفحة الرئيسية، ظهور تدريجي للأقسام، عدّاد دائري للمهلة، احتفال لما يتثبّت المقعد. وبتتوقف تلقائياً للي مفعّل "تقليل الحركة" بجهازه.

**لإسناد (`/admin`)**
- أرقام: مقاعد مثبّتة، دفع بحاجة تأكيد، بمهلة الدفع، قائمة الانتظار.
- المقاعد لكل مسار، فلترة بالحالة والمسار، بحث، وتصدير Excel (CSV).
- لكل طالب: تحديد موعد مقابلة، قبول (بيبلّش المهلة)، رفض، عرض صورة التحويل، تأكيد الدفع أو رفضه مع رسالة وتمديد، إعطاء المقعد لأول واحد بالانتظار، وأزرار واتساب جاهزة برسائل مكتوبة.
- ملف شخصي: صورة للأدمن (بتظهر بالقائمة الجانبية)، الاسم، المسمى، الإيميل، وكلمة السر.
- الإعدادات: طرق الدفع وأرقامها، الرسوم، مدة المهلة، عدد المقاعد لكل مسار، فتح/إغلاق التسجيل، ورقم واتس للاستفسارات.

**الأمان**
- صور التحويلات وصور البروفايل محفوظة بمجلد خاص (`storage/app/private`)، وبتنفتح بس بروابط موقّعة ومؤقتة بتنعمل للإدارة.
- حماية CSRF، وحدود للطلبات المتكررة، ورفع صور فقط (JPG/PNG/WEBP/PDF حتى 5 ميجا).

## التشغيل

بدك PHP 8.3+ و Composer.

```bash
cp .env.example .env
# عدّل بـ .env:
#   APP_URL=https://your-domain.com
#   ADMIN_EMAIL=...  ADMIN_PASSWORD=...
composer run setup
php artisan serve
```

`composer run setup` بيثبّت المكتبات، بيعمل قاعدة بيانات SQLite، وبيعمل حساب الإدارة. إذا ما حطيت `ADMIN_PASSWORD` بينطبعلك كلمة سر مولّدة.

بعدها:
1. ادخل على `/admin/login`.
2. روح على **الإعدادات** ← عبّي أرقام بنك فلسطين وجوال باي وفعّلهم.
3. حط عدد المقاعد لكل مسار ورقم واتس إسناد.

### الخط (Thmanyah Sans)
رخصة خط ثمانية ما بتسمح بإعادة توزيع ملفاته، فما حطيتها جوّا المشروع:
1. نزّل الخط من صفحة ثمانية الرسمية (بيوصلك على الإيميل).
2. فك الملف وحط ملفات الخط زي ما هي بمجلد `public/fonts/thmanyah`.
3. حدّث الصفحة، والموقع بيستخدمه لحاله وبيعرف الأوزان من أسماء الملفات.

لحد ما تحطه، الموقع بيشتغل بخط IBM Plex Sans Arabic كاحتياطي.

### إذا كان المشروع منزّل عندك من قبل
بعد ما تستبدل الملفات، شغّل:
```
php artisan migrate
php artisan view:clear
```

### المهلة التلقائية
النظام بيفحص المهل كل ما حدا يفتح صفحة. ولتحديث أدق على السيرفر، أضف هالسطر لـ cron:

```
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

### الرفع على استضافة
- خلي الدومين يأشّر على مجلد `public`.
- `APP_ENV=production` و `APP_DEBUG=false` (موجودين جاهزين).
- بدك MySQL بدل SQLite؟ غيّر `DB_CONNECTION=mysql` وبيانات القاعدة بـ `.env` وشغّل `php artisan migrate --force && php artisan db:seed --force`.
- تأكد إنه مجلدي `storage` و `bootstrap/cache` قابلين للكتابة.
